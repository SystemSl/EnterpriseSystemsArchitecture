## Требования
* **Java:** JDK 23
* **СУБД:** PostgreSQL 18
* **Сервер приложений:** GlassFish 8
* **Сборщик:** Apache Maven

# Инструкция по развертыванию и настройке проекта

Руководство по настройке базы данных, конфигурированию сервера приложений GlassFish и развертыванию веб-приложения.

---

### Шаг 1. Подготовка базы данных (PostgreSQL)
1. Создайте в PostgreSQL новую базу данных с именем **`server_db`**.
2. Выполните скрипт **`src/main/resources/sql/init.sql`** для создания структуры таблиц (сущностей предметной области).

---

### Шаг 2. Добавление JDBC-драйвера в GlassFish
1. Скачайте официальный JDBC-драйвер PostgreSQL (`.jar`-файл).
2. Скопируйте скачанный `.jar` в каталог сервера: `glassfish8/glassfish/domains/domain1/lib/`
3. Запустите сервер GlassFish через консоль: `glassfish8\glassfish\bin\asadmin start-domain`.

---

### Шаг 3. Настройка пула и ресурса в консоли GlassFish
1. Откройте в браузере веб-консоль администратора: **`http://localhost:4848`**.
2. **Создание Connection Pool:**
   * Перейдите в **Resources** -> **JDBC** -> **JDBC Connection Pools** и нажмите **New...**.
   * Укажите имя пула: **`server-db-pool`**, тип ресурса `javax.sql.DataSource`, вендор — `PostgreSQL`.
   * В свойствах подключения укажите параметры вашей БД: `serverName` (localhost), `portNumber` (5432), `databaseName` (`server_db`), `user` и `password`.
   * Сохраните пул и обязательно нажмите кнопку **Ping**, чтобы убедиться в успешном соединении (`Ping Succeeded`).
3. **Создание JDBC-ресурса:**
   * Перейдите в **Resources** -> **JDBC** -> **JDBC Resources** и нажмите **New...**.
   * Задайте JNDI-имя: **`jdbc/serverDS`**.
   * В поле выбора пула укажите созданный ранее **`server-db-pool`**.
   * Сохраните настройки.

---

### Шаг 4. Сборка проекта
1. Выполните команду сборки архива: `mvn clean package`
2. Убедитесь, что в директории `target/` сгенерировался готовый файл с расширением **`.war`**.

---

### Шаг 5. Развертывание
1. В консоли GlassFish (`http://localhost:4848`) перейдите в раздел **Applications**.
2. Нажмите кнопку **Deploy...**.
3. Выберите опцию загрузки файла с локального компьютера и укажите путь к сформированному **`.war`** файлу.
4. Подтвердите развертывание, нажав **OK**.

---

### Шаг 6. Проверка работы
1. В списке **Applications** найдите развернутое приложение и перейдите по ссылке **Launch** (или откройте `http://localhost:8080/EnterpriseSystemsArchitecture/` в браузере).
2. Проверьте работоспособность базовых операций:
   * Добавление новой записи через форму.
   * Редактирование существующей записи.
   * Удаление записи.
